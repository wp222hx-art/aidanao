# 企业智脑 · 老板的 AI 经营指挥舱（图形化交互原型）

基于《企业智脑可行性与产品功能策划案》与《云工智合佳 AI 智能体产品完整规划》搭建的**全图形化企业数字孪生平台**原型。

## 一、创建流程（4 步图形化向导）
1. **智能识别行业（新增）**：顶部输入企业名称 → 检索维基百科与公开资讯 → 遍历 97 个行业大类做关键词打分 → 自动归类，给出 TOP3 候选、置信度和识别依据，可一键切换
   **行业星图**：GB/T 4754-2017《国民经济行业分类》20 门类 / 97 大类 + 细分关键词，支持搜索（如“预制菜/光伏/灵活用工”）
2. **企业雷达扫描**：输入企业名 → 实时检索维基百科 + 必应公开资讯 → 生成企业定位、价值链、七域诊断、商业模式画布、机会/风险（标注置信度与证据）
3. **部门布局画布**：AI 按行业推荐部门节点（24 个预置部门库），支持拖拽添加、自定义部门、拖动布局、神经连线
4. **人员录入**：录入简历/上传 .txt → 自动识别技能 → 价值评分；可 AI 一键生成示例员工

## 二、指令驱动工作流（核心机制）
**原则：没有老板指令就没有工作。** 时钟只驱动机制检查点，不凭空制造任务；无指令时全体 Agent 待命。

每条指令沿 8 个阶段逐段推进，到哪个阶段就由哪个角色处理：

`老板下达 → ①拆解(智脑) → ②方案确认(老板·闸门①) → ③分发(部门集群) → ④执行(Agent) → ⑤校验(AI质检) → ⑥审批(老板·闸门②) → ⑦交付(部门) → ⑧复盘提升(知识库)`

| 机制 | 作用 |
|---|---|
| **循环** | 校验 <80 分 → 带评语返工；方案被驳回 → 带意见重新拆解；指令验收“部分达成” → 迭代下一轮；勾选“每日例行” → 每天 09:00 自动续跑 |
| **审批** | 闸门① 方案确认（可在工作机制页关闭）；闸门② 高风险动作 / L1 Agent 成果审批；返工后仍不达标 → 人工复核；驳回意见自动成为下一轮依据 |
| **校验** | 任务级五维评测（准确30/证据20/时效15/合规15/价值20，≥80 通过）+ 指令级整体验收（达成/部分/未达成）；12:00 进度校验、15:00 督办巡检（L1 Agent→L2 负责人→L3 老板） |
| **提升** | 指令验收后复盘提炼经验 → 写入企业经验库 → 自动注入同部门后续拆解与执行；Agent 连续 2 次 ≥88 分晋级，返工/人工兜底降级 |

### 调度中枢（默认首页）
- **阶段节点行**：老板 + 8 阶段，实时计数；两道闸门虚线高亮；SVG 画出主流向与 5 条循环回路（迭代、经验注入、驳回重拆、返工、驳回返工），机制触发时回路脉冲
- **指令轨道**：每条指令一行，按阶段显示 完成/进行中/跳过，点击聚焦（其它指令淡出，日志只看该指令）
- **部门 Agent 集群泳道**：每部门一行，Agent 点阵（亮起=在处理），任务卡片按阶段落位，颜色=所属指令
- **右侧**：老板指令输入（可设每日例行）→ 指令队列（8 段进度点）→ 按指令过滤的工作流日志
- **指令详情**：阶段进度、目标、方案确认/驳回、拆解表、验收与复盘、迭代下一轮、例行、取消、流转记录
- **数字孪生**：等距办公室按 老板→智脑→质检→知识库→各部门 的流程排布，作为可视化补充

## 三、业务模块
| 模块 | 内容 |
|---|---|
| 工作机制 | 四机制卡片（循环/审批/校验/提升）、每日节拍、例行指令与返工、督办清单、校验记录、经验库、Agent 排行 |
| 审批闸门 | 按 方案确认 / 成果审批 / 人工复核 / 对外发布 分组，一键全部批准，驳回可填意见 |
| 商机雷达 | 检索也是指令：扫描 = 下达指令给销售部；跟进商机 = 生成“商机指令”走完整流程 |
| Agent 集群 | 核心 Agent + 执行体，L1 建议 / L2 标准 / L3 自主 / L4 禁止自主 |
| 经营驾驶舱 | 六引擎、七域雷达、趋势 |
| 内容工厂 | Canvas 海报 / 动画视频，Genspark 真实图片与视频生成 |
| 价值账本 / 组织人才 | ROI 口径、部门与人才；部门抽屉可“向本部门下达指令”（同样走校验与审批） |

## 四、接口
- `GET /api/scan?name=&industry=` 企业公开情报扫描
- `GET /api/leads?q=` 公开采购/招标线索检索（经采购意图词过滤）
- `GET /api/health`
- `POST /api/ai/command` 指令拆解（支持 feedback 驳回意见、knowledge 经验注入）
- `POST /api/ai/execute` Agent 执行（goal/knowledge 注入，`evaluate:false` 只出成果）
- `POST /api/ai/evaluate` 五维校验 · `POST /api/ai/review` 指令验收与复盘（score/verdict/lessons/next）

## 五、数据与边界
- 状态存储于浏览器 localStorage（原型阶段）；生产建议迁移 Cloudflare D1
- 公开检索结果有限时，线索与画像由行业模型推断，并在界面标注“模型推断”
- 运营数据为仿真演示，不代表真实经营结果；工商/招投标/CRM 需授权接入

## 七、Genspark 真实能力接入（企业主本人授权）
后端 `src/ai.ts` 以与 `gsk` CLI 相同的协议调用 Genspark（`/api/tool_cli/<tool>` + `/api/llm_proxy/v1`），密钥只存在服务端：
- 本地：`.dev.vars` 中的 `GSK_API_KEY`（已 gitignore）
- 生产：`wrangler pages secret put GSK_API_KEY`；可选 `BRAIN_ACCESS_CODE`（访问口令，防止他人消耗积分）、`AI_MODEL`（默认 gpt-5-mini）

| 接口 | 能力 | 用到的 Genspark 工具 |
|---|---|---|
| `GET /api/ai/status` | 授权状态、套餐、积分 | me |
| `POST /api/ai/classify` | 企业名称 → 全网检索 → AI 归入 97 个国标大类（TOP3+依据） | batch_web_search + LLM |
| `POST /api/ai/profile` | 深度画像：定位/价值链/七域诊断/画布/机会/风险/竞品/找单关键词/推荐部门 | batch_web_search + LLM |
| `POST /api/ai/leads` | 商机雷达：全网检索采购/招标 → AI 分级 A/B/C、采购方、下一步 | web_search + LLM |
| `POST /api/ai/command` | 老板指令 → 可验收的部门任务（标记高风险需审批） | LLM |
| `POST /api/ai/execute` | Agent 真实执行（必要时先检索）+ 独立 AI 质检官五维评测 | web_search + LLM×2 |
| `POST /api/ai/evaluate` | 单独评测 | LLM |
| `POST /api/ai/resume` | 简历解析：工龄/技能/价值分/定位/优势/短板/搭档 Agent | LLM |
| `POST /api/ai/brief` | AI 经营日报 | LLM |
| `POST /api/ai/copy` | 合规营销文案 + 画面/视频提示词 | LLM |
| `POST /api/ai/image` / `video` | 海报画面 / 5 秒宣传视频 | image_generation / video_generation |
| `POST /api/ai/agent` + `GET /agent/status` | 交给 Genspark 超级智能体深度执行（异步） | create_task / task_status / task_info |
| `GET /api/ai/file` | Genspark 文件代理（换取临时地址） | file/download |

运行规则：评测 ≥80 通过；<80 带评审意见自动返工一次；仍不达标转人工复核；老板可人工通过 / 写意见打回 / 升级超级智能体。
真实任务并发 2 个；商机雷达每个仿真日自动 1 次且真实间隔 ≥8 分钟；视频/超级智能体需二次确认。未连接时自动回退仿真模式。
